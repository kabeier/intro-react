All the code, one branch per lecture

Missed a lecture, or your code won't run? This GitHub repo has the Pokemon app as it stands at the end of every lecture, so you can pick up from any point.

Open the repo on GitHub ↗

1How the repo works

  • Each lecture has its own branch. A branch is a version of the project.
  • A branch holds the code at the end of that lecture.
  • So the start of a lecture is the branch of the lecture before it.
  • Inside a branch there's one commit per feature, matching the features in the Code Explorer.
start ─→ Unit 2 L1 ─→ Unit 2 L2 ─→ Unit 3 L1 ─→ … ─→ Unit 9 L2 = main
         (end of L1)  (end of L2)

To start Unit 2 Lecture 2, use the end of Unit 2 Lecture 1.

You can read this repo but not push to it. To push, make your own copy:

    
    
      
  1. On GitHub click Fork, and untick "Copy the main branch only". If you leave it ticked, the lecture branches are not copied.

  2. Clone your fork (your username in the address), then use the same commands as above.
