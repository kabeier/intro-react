Starting any of these projects

npm create vite@latest my-project -- --template react
cd my-project
npm install
npm run dev

"Vite requires Node.js version 20.19+"? Use Node 24 (or the Docker setup from lecture 1: FROM node:24). Page won't load from Docker? Check "dev": "vite --host" and -p 5173:5173.

Setting up Cypress in your project

npm install cypress --save-dev
npm run cy:open

Cypress won't start? It runs on your laptop (not in Docker) and needs Node 22, 24 or 26. Start the app first (port 5173), and set supportFile: false in cypress.config.js.

Deploying

npm install --save-dev gh-pages
npm run deploy

Blank page on GitHub Pages? base in vite.config.js must be '/<your repo name>/', only in production: defineConfig(({ mode }) => ({ base: mode === 'production' ? '/repo/' : '/', … })). Refresh gives 404? Use the hash router in production. The two workflow files are in the Code Explorer to copy.
