Two tools, two jobs

React

A JavaScript library for building the page from components: functions that return what to show.

Vite

The dev tool: creates the project, runs a dev server with hot reload, and builds the final files.

React decides what is on the page. Vite serves it to the browser while you work.

Say: "Unit 1 we changed the page by hand with querySelector. React lets us describe the page; it does the DOM work."

Vite = French for "fast". Its dev server reloads the page the moment you save.

How React updates the page (the virtual DOM)

Unit 1, by handReact
You write"find this element, change its text""the page should look like this" (JSX)
When data changesyou find and fix every element yourselfReact runs your component again
Then—compares the new result with the previous result, and changes only what differs in the real DOM

The virtual DOM is React's copy of the last render, not a copy it checks the real page against.

Say: "React keeps the last thing your component returned. Next time, it compares the new one with that, and touches the real page only where they differ."

Different from the curriculum (until merged): it said the virtual DOM is "compared against the DOM". React compares render output with the previous render output.

JSX: HTML-like, with JavaScript rules

RuleExample
Return one root<> … </> (a fragment) around siblings
Close every tag<img />, <input />
{ } = JavaScript here<p>{message}</p>
className, htmlForclass and for are JavaScript words
Props are camelCaseonClick, style={{ fontSize: 20 }}
Components start with a Capital<App /> vs <div>

Every Fix It problem today breaks one of these rules.

Say: "JSX looks like HTML but it is JavaScript underneath, so it follows JavaScript's rules."

All your CSS is one stylesheet

You writeWhat the browser gets
import './App.css' in App.jsx
import './Card.css' in Card.jsx		one big stylesheet for the whole page
.title { color: red } in Card.cssevery element with class title turns red, in any component
two files both define .titlethey clash: the one loaded last wins

A CSS file is not private to the component that imports it.

Say: "Importing a CSS file in a component does NOT scope it to that component. Vite adds every imported file to the same page."

Fixes students meet later: unique class names, CSS Modules (unit 5, lecture 2), Tailwind (unit 6).
