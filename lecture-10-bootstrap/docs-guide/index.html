How to use the React Bootstrap docs

A component library is only as good as your ability to look things up. This page shows which of the two docs sites to open, how to read a component page, and where every part of our app lives.

1Two docs sites, two jobs

SiteOpen it forExample from our app
React Bootstrap
react-bootstrap.github.io		Components and their props<Card bg="dark">, <Button variant="danger">
Bootstrap
getbootstrap.com/docs/5.3		CSS classes (utilities) and the colour namesclassName="mb-0", text-capitalize

A tag with a capital letter (<Card>)? React Bootstrap. A word in className? Bootstrap.

Watch out: Bootstrap's own pages show plain HTML like <div class="card">. In React, use the component (<Card>) instead.

2Read a component page

Open Cards next to this guide and find each part:

Left: the menuLayout, Forms, Components. Every component has one page.
Middle: the page① ExamplesEach example has a Result (what it looks like) and a Live Editor: change the code and the result changes.② API (at the bottom)The import line, then a table of every prop.
Right: the page listJump to an example, or straight to API.

Reading the API table

This is part of the real table for Card:

NameTypeDefaultDescription
asReact.ElementType'div'Element used to render the component.
bg'primary' | 'secondary' | 'success' | 'danger' | 'warning' | 'info' | 'dark' | 'light'Sets card background
text'primary' | … | 'white' | 'muted'Sets card text color
bodybooleanfalseCreates a Card with a Card.Body inside
  • Name = the prop you write: <Card bg="dark">
  • Type = the values it takes. | means "or": pick one.
  • Default = what you get if you leave it out
  • boolean = write the prop alone to turn it on: <Card body>

Examples show you what it looks like. The API table tells you every prop it takes.

4Every new component: three steps

  1. Find it in the left menu (or search). Pick the example that looks closest to what you want.
  2. Copy the import from the API section: import Alert from 'react-bootstrap/Alert'
  3. Change it with props from the API table, not with your own classes

In our app: Bootstrap's CSS is imported once, in main.jsx (import 'bootstrap/dist/css/bootstrap.min.css'). Forget it and the components show up unstyled.

5Try it: look these up

Find the page, then the prop in its API table. Write your answer down, then check.

1. Make the Remove button an outline button: red border, no fill.
Answer

variant="outline-danger". Page: Buttons → "Outline buttons".

2. Make the Shiny button smaller.
Answer

size="sm". Page: Buttons → "Sizes".

3. Make the Pokedex badge round (a pill).
Answer

Add pill: <Badge pill bg="secondary">. Page: Badges → "Pill badges".

4. Give each Pokemon card a coloured border.
Answer

<Card border="primary">. Page: Cards → "Border Color".

5. Stack the card's buttons on top of each other instead of side by side.
Answer

Remove direction="horizontal": a Stack is vertical by default. Page: Stacks.

6. Show a yellow warning box when the search finds nothing.
Answer

import Alert from 'react-bootstrap/Alert', then <Alert variant="warning">No Pokemon found</Alert>. Page: Alerts.

6It looks wrong?

  • No styles at all: the CSS import is missing from main.jsx
  • "does not provide an export named…": import each component from its own path: import Card from 'react-bootstrap/Card'
  • A prop does nothing: check the API table. The value must be one from the Type list, spelt the same.
  • Tailwind and Bootstrap fight: keep @import "tailwindcss" important;, and use one library per component
