What is React Bootstrap?

  • Bootstrap's components rewritten as React components
  • bootstrap = the CSS · react-bootstrap = the components
  • One import per component: import Card from 'react-bootstrap/Card'

You need both packages: components and their CSS.

Why Bootstrap wins: cascade layers

RuleWhere it livesWins?
Tailwind .gap-5 { gap: 1.25rem }inside @layer utilitiesno
Bootstrap .gap-5 { gap: 3rem !important }no layeryes: !important, and unlayered
Tailwind with importantlayer, !importantyes: layered !important beats unlayered !important

Import order does not fix it; important does.

The plan: Why Bootstrap won that clash: the same class name in both libraries, and cascade layers.

Point at each row, top to bottom: Tailwind's gap-5, Bootstrap's gap-5, then Tailwind with important.

This is why "just import Bootstrap first" (the curriculum's order) isn't enough with Tailwind v4.

Two libraries in one app: the rules

  • @import "tailwindcss" important; so utilities win clashes
  • Bootstrap for components (card, buttons, header, form); Tailwind for layout (column, card row)
  • One library per component: no Tailwind classes on Bootstrap parts
  • A guard test (computed styles) tells you when a clash comes back

Our app: mostly Bootstrap, a little Tailwind.
