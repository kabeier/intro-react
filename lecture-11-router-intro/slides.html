Reading a route

{ path: '/', element: <App />, children: [ … ] }
KeyMeans
paththe URL this route matches
elementthe JSX to show (with < />)
childrenroutes shown inside this one's <Outlet />
index: truethe child for the parent's own path

A route is an object: URL → element.

Unknown keys (a typo like chidren) are silently ignored: Fix It problem 6.

Pages mount and unmount

You go from / to /aboutWhat happens
Appstays mounted (it's the layout)
HomePage, Counter, PokeSearchunmount: their state is thrown away
AboutPagemounts fresh

State in a page lives only while you're on that page.

This is the problem unit 8 lecture 2 solves (state moves up to App).

Mental model

  • The router reads the URL and picks a route
  • RouterProvider runs it; routes are objects (path, element, children)
  • App is the layout; the page goes in <Outlet />
  • Leaving a page unmounts it
