Link or useNavigate?

SituationUse
the user clicks something to go to a page<Link to>
go somewhere after logic: a form passed its check, a request finishednavigate('/…')
Backnavigate(-1)

Link by default; navigate when code decides.

The plan: When to use Link, and when to use useNavigate.

Different from the curriculum (until merged): it suggests useNavigate in place of Link. Links are real <a> tags: right-click, open in new tab, screen readers.
