Why the cards disappear

StepWhat React does
search BulbasaurPokeSearch's list: [pikachu, bulbasaur]
click AboutHomePage unmounts: PokeSearch's state is thrown away
click HomeHomePage mounts fresh: list = [] (then Pikachu loads again)

State dies with the component that owns it.

The console shows the mounted/unmounted logs.

Move it up to the layout

App
owns the list; never unmounts
→ <Outlet context={…} /> →
any page
useOutletContext()
  • Same rule as unit 5: shared state lives in the closest common parent
  • Pages aren't written as tags in App, so no props: the Outlet carries a context
  • Inside the page it's normal props again (PokeSearch → PokeContainer → PokeCard)

The layout owns what every page needs.

Different from the curriculum (until merged): context is not "global state"; only pages under that Outlet can read it.

Same names on both sides: it's one object.

Fix It: a renamed key, an array instead of an object, the hook used in App itself.
