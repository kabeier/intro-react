Asynchronous: start it, keep going, handle the answer later

SynchronousAsynchronous
a phone call: you wait on the linea text message: you do other things until the reply
the page freezes until the answerthe page stays usable
A promise is…means
pendingno answer yet
fulfilledthe answer arrived
rejectedit failed (404, network down…)

axios.get returns a promise at once. The data comes later.

The plan: What asynchronous means: start the request, keep going, handle the answer when it comes.

Say: "JavaScript has one thread. If it waited for the network, every click would freeze. So it hands back a promise: 'I'll tell you when it's done.'"

.then or await: the same promise

axios.get(url)
  .then((response) => …)
  .catch((error) => …)
  .finally(() => …)
try {
  const response = await axios.get(url)
  …
} catch (error) { …
} finally { … }

await only works inside an async function, and it pauses that function, not the page.

The plan: Side by side: .then and await are the same promise, written two ways.

Most code you'll read uses async/await. Both are fine; don't mix them in one function.
