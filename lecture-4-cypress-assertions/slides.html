  1. Which test? The ✗ line names it
  2. Which line? The message names the selector or assertion
  3. Test wrong or app wrong? Do it by hand in the browser
  4. Fix the one that is wrong, run again

Why stub the API?

Real PokeAPIStubbed (cy.intercept)
Speednetwork round trip every searchinstant
Same result every run?no: slow days, outages, data changesyes
Errors on purposehard (need a missing name){ statusCode: 404 }

Fixtures = saved answers. The app can't tell the difference.

The plan: Why fake the API: real requests are slow, can go down and can't fail on demand.

Our fixtures hold only the fields the app reads; we'll add fields when later units read more.
