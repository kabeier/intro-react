How state changes the page

event
→
setState(new)
→
App() runs again
→
React updates only what changed
  • State = a value React remembers between renders
  • Changing it with its setter = "render again, please"
  • React compares the new render with the last one (the virtual DOM) and changes only the differences

Never change state directly; always through its setter.

The plan: The loop to remember: an event calls a setter, the component runs again, and React updates the page.

  • Tests describe what users see, so they survive rewrites
