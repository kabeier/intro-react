What is a component?

RuleExample
a function that returns JSXfunction Counter() { return <h3>…</h3> }
name in PascalCaseCounter, PokeCard (not counter)
exported, then importedexport default Counter · import Counter from './…'
used like a tag, never called<Counter />

Capital letter = component. Lowercase = HTML tag.

The plan: The rules for a component: a function, a PascalCase name, returns JSX, exported and imported.

Different from the curriculum (until merged): it says "camelCase with an uppercase letter"; the name is PascalCase.

What are props?

You writeThe component gets
<PokeCard pokemon={pokemon} rmData={rmData} />{ pokemon, rmData }
<Button onClick={f}>Click me!</Button>{ onClick: f, children: 'Click me!' }
  • Props = the component's arguments, as one object
  • children = whatever is between the tags
  • Props are read-only: never change them inside

Attributes in, one props object out.

The plan: Props are the arguments of a component. What you write, and what the component gets.

Different from the curriculum (until merged): it calls ({ pokemon }) "deconstructing"; it's destructuring.
