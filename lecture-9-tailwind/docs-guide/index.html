How to use the Tailwind docs

Nobody remembers every class. Tailwind developers keep the docs open and look things up. This page shows how to find a class fast, how to read a docs page, and where every class from the lecture lives.

1Where the docs are

  • tailwindcss.com/docs: the official docs
  • Check the version badge next to the logo: it should say v4. Our app uses Tailwind v4.
  • Play (top menu) opens the Tailwind Playground: try classes in the browser, no install needed

Watch out for old answers. Blog posts, videos and AI answers often show v3 setup: a tailwind.config.js file and @tailwind base;. In v4 you use the Vite plugin and @import "tailwindcss";, like we did in class.

2Find a class

  1. Press Ctrl K (Mac: ⌘ K) on any docs page
  2. Type the CSS property you want, in plain words: padding, rounded, shadow, center
  3. Pick the page. Each page is one CSS property.

3Read a docs page

Every Tailwind page has the same three parts. Open padding next to this guide and find each one:

Left: the menuEvery page, grouped: Layout, Spacing, Typography, Borders…
Middle: the page① The quick reference tableClass on the left, the Styles (the real CSS) on the right. Press Show more to see all of it.② ExamplesA small demo and the HTML for each way to use it.
Right: On this pageJump straight to an example, or to Responsive design.

Reading the table

The table saysIt means
p-<number> · padding: calc(var(--spacing) * <number>)Put any number after p-. --spacing is 0.25rem, so p-4 = 4 × 0.25rem = 1rem.
px-<number> · padding-inlinex = left and right
py-<number> · padding-blocky = top and bottom
p-[<value>]Square brackets = your own value, like p-[13px]. Use it rarely.

Class on the left, real CSS on the right. That table is the whole answer most of the time.

5Variants: hover:, focus:, md:, dark:

A variant goes in front of any class and adds a condition. Each one has its own page:

VariantMeansDocs page
hover: focus:only while the mouse is over it / while it has focushover, focus, and other states
sm: md: lg:only from that screen width up (sm = 40rem, md = 48rem)responsive design
dark:only in dark modedark mode

Mobile first: a class with no prefix works on every screen. md: changes it on bigger screens.

6Try it: look these up

Use Ctrl K for each one. Write your answer down, then check.

1. Make the card corners rounder than rounded-xl.
Answer

rounded-2xl (or rounded-3xl). Page: border-radius.

2. Add padding to the top only.
Answer

pt-4. t = top. Page: padding → "Adding padding to one side".

3. Give the header a purple background.
Answer

bg-purple-700 (any shade, 50 to 950). Pages: background-color, every colour on colors.

4. Make the Pokemon's name italic.
Answer

italic. Page: font-style.

5. Underline a link only when the mouse is over it.
Answer

hover:underline. Page: text-decoration-line.

6. Hide something on phones, and show it from md up.
Answer

hidden md:block. Pages: display and responsive design.

7The class is right, but nothing changes?

  • Spelling: a misspelt class does nothing, with no error. Compare it with the docs table.
  • React: className, not class
  • Setup: the Vite plugin in vite.config.js, and @import "tailwindcss"; in index.css
  • VS Code: install Tailwind CSS IntelliSense. Hover a class to see its CSS.
  • The browser: DevTools → Elements → Computed shows what the page really used
