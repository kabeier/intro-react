Components in folders, and CSS Modules

Why a CSS file in React is never private to its component, how to give every component its own folder, and how a CSS Module keeps a component's class names to itself. Every editor below is live: change the code and watch the app.

1All your CSS is one stylesheet

  • Card.jsx imports Card.css; Banner.jsx imports Banner.css.
  • Both files have a rule called .title.
  • Vite puts every imported CSS file into one stylesheet for the whole page.
  • So both rules apply to both titles, and the rule loaded last wins: the card's title is blue and big, not red.

Importing a CSS file in a component does not make it private to that component.

Every line explained: open this step in the Code Explorer.

2One folder per component

Give each component a folder with everything it needs:

src/
  App.jsx
  components/
    Card/
      Card.jsx       the component
      Card.css       its styles
      index.js       export { default } from './Card'
    Banner/
      Banner.jsx
      Banner.css
      index.js
  • index.js is the folder's front door: it passes on the component.
  • Importing a folder loads its index.js, so the import stays short: import Card from './components/Card'.
  • The folder can grow (styles, tests, small helpers) without changing any import.
⚠ Folders organise files, but they do not scope CSS: the card's title is still blue. Step 3 fixes that.

Open this step in the Code Explorer.

3A CSS Module keeps Card's classes to itself

  1. Rename Card.css to Card.module.css. The rules don't change; the .module.css name is what matters.
  2. Import it with a name: import styles from './Card.module.css'.
  3. Use the names from the object: className={styles.title} instead of className="title".
import styles from './Card.module.css'

function Card() {
  return (
    <div className={styles.box}>
      <h2 className={styles.title}>Card title</h2>
      ...
  • styles is an object: { box: '_box_1x2y3', title: '_title_4z5w6' }. Vite makes the unique names.
  • Only elements with that unique class get the rule. Banner's global .title can't reach Card any more.
  • Right-click the red title → Inspect: the class looks like _title_13ves_7.

Open this step in the Code Explorer.

4Your turn: give Banner a module

Banner still uses the global Banner.css. Make it a CSS Module, with the size as a second class .big:

  1. Fill in src/components/Banner/Banner.module.css (already open, empty) with .title { color: royalblue; } and .big { font-size: 40px; }.
  2. In Banner.jsx, import it as styles and use both classes on the h2.
  3. Delete Banner.css (or just stop importing it).

Two classes on one element: join them in a template string, className={`${styles.title} ${styles.big}`}.

The empty Banner.module.css tab is ready for you. The check looks at the result on the page.

Show the answer 
// Banner.module.css
.title {
  color: royalblue;
}

.big {
  font-size: 40px;
}

// Banner.jsx
import styles from './Banner.module.css'

function Banner() {
  return <h2 className={`${styles.title} ${styles.big}`}>Banner title</h2>
}

export default Banner
